# car-widgets-autodash: daily Reel workflow
Instagram: next.gen.studio.app (Business) via Buffer channel id 6af841af62b70b94b02b77bb, org 6af8413f700167741ad07cb8.
Source: TikTok @car.widget. Goal: re-edit one NEW video per run, append the Car Widgets: AutoDash ad (assets/ad.mp4), publish as Instagram Reel.

## Rules
1. Never repost the original unedited. Never reuse an ID listed in posted.json.
2. Download with yt-dlp (no watermark): `pip install --break-system-packages yt-dlp`; list: `yt-dlp --flat-playlist --playlist-end 20 --print "%(id)s | %(upload_date)s | %(duration)s | %(title).80s" https://www.tiktok.com/@car.widget`. Pick the newest ID not in posted.json that downloads as a normal video (5-60 s). Skip photo posts.
3. Banner: look at 4 frames, find where the original burned-in caption sits, write a NEW 2-line English hook for the video topic: `cd assets && python3 make_banner.py "LINE ONE" "LINE TWO"`. The banner covers y=195..465 of the 1080x1920 frame; if the original text sits elsewhere, adjust y in make_reel.py (overlay y=195) so no original text leaks.
4. Render: `cd assets && python3 make_reel.py ../src.mp4 ../reel.mp4 --badge badge.png --icon icons/<name>.png --sfx-start sfx/<a>.wav --sfx-badge sfx/<b>.wav --sfx-icon sfx/<c>.wav --sfx-card sfx/<d>.wav` (no zoom; bottom App Store card visible from the first second; music 12 %; ad appended with a soft transition). Layout, timing and positions stay fixed; only the sticker and sound CHOICES change per video.
4a. STICKERS + SOUNDS PER VIDEO (user rule, 17 Nov 2026): do NOT use the same NEW badge, star and sounds every time. After looking at the frames, choose them to fit what this video shows:
   - Badge: `cd assets && python3 make_badge.py "TEXT" <color> badge.png`, 1-2 short words, max ~10 characters (e.g. NEW, HOT, TRY THIS, iOS 27, GLOW UP, WOW, MUST TRY, XMAS VIBES, F1 MODE, EASY). Colors: red orange gold green teal blue purple pink black.
   - Icon: one file from assets/icons/ (star sparkles heart fire snowflake christmas_tree gift santa bell rocket lightning hundred eyes mind_blown trophy crown music sun moon pumpkin ghost party car race_car phone clock check thumbs_up money coffee map fuel battery gear palette camera heart_eyes cool chef_kiss pin calendar weather checkered_flag flag_us turkey leaf valentine shamrock firework). New icons can be rendered from /usr/share/fonts/truetype/noto/NotoColorEmoji.ttf (300x300 RGBA, emoji ~270 px).
   - Sounds from assets/sfx/: whoosh_soft whoosh_fast whoosh_classic swipe pop_soft pop_bubble pop_classic ding chime sparkle click jingle_bells bass_hit rise cash notify engine_rev. Start = an intro whoosh/swipe/rise/jingle; badge = whoosh/sparkle/bass_hit/notify; icon = pop/ding/sparkle/cash; card = pop/click/ding.
   - Match the topic (Christmas: XMAS badge, tree/santa/snowflake, jingle_bells/chime; racing: F1 MODE, checkered_flag/race_car, engine_rev/whoosh_fast; music: music icon, notify; money/fuel: money/fuel, cash) and do not repeat the exact combination of the previous reel (check the last commit messages). Name the chosen badge, icon and sounds in the commit message and the report.
5. QC: ffprobe 1080x1920 h264+aac; extract 4-6 frames and look (no original text leaking, stickers/card inside frame); volumedetect max < -0.3 dB.
6. Caption (English, SEO-focused, applies to EVERY platform and EVERY tool: Buffer AND Upload-Post): NEVER put the App Store link or any URL in the caption/description/title. First ~125 chars = main search keywords in a natural sentence (e.g. CarPlay, iOS 27, CarPlay widgets, custom CarPlay dashboard, the video topic), then 1-3 short keyword-rich sentences about what the video shows, then a soft CTA without a link (e.g. "Search Car Widgets: AutoDash on the App Store."), then a blank line and 4-5 hashtags: #carplay #ios27 #carwidgets #autodash + at most 1 topic tag. No credit, no permission wording, no @car.widget, do not name competitor apps. YouTube text must not contain < or >.
7. Publish: copy reel.mp4 to `reels/<tiktok_id>.mp4`, commit and push to main of THIS repo only, verify `https://raw.githubusercontent.com/next-gen-studio/autodash-reels/main/reels/<id>.mp4` returns 200, then Buffer create_post: channelId above, schedulingType automatic, mode shareNow, metadata.instagram {type: reel, shouldShareToFeed: true}, assets [{video:{url:<raw url>, metadata:{thumbnailOffset:<cover ms>}}}] (see rule 12). Check get_post until status is sent and report the externalLink.
12. COVER (thumbnail): pick the cover from the MAIN video (before the appended ad), a sharp frame where the CarPlay screen with the app clearly visible is in view (banner hook visible, no motion blur, no hand covering the screen). Extract candidate frames, look at them, choose one, and pass its time in milliseconds as video metadata.thumbnailOffset on every Buffer post that supports it (Instagram, TikTok), and for Upload-Post save that frame as `covers/<id>.jpg` (1080x1920 JPG, `ffmpeg -ss <sec> -i reels/<id>.mp4 -frames:v 1 -q:v 2 covers/<id>.jpg`), push it, verify its raw URL returns 200, and pass it as platformOptions.instagramCoverUrl (plus instagramThumbOffset = ms). If a platform cannot take a custom cover through the tool (e.g. YouTube via Buffer), say so in the report. Never use a frame from the ad segment.
8. Add the TikTok ID to posted.json, commit, push.
9. SAFE AREA (mandatory, every platform: Instagram, TikTok, YouTube Shorts): read SAFE_AREA.md. Safe box is x 90..890, y 230..1480 of the 1080x1920 frame; all text, the banner hook, stickers, the photo and the App Store card must sit inside it. make_reel.py and make_photo_reel.py already place them there; never move them outside. In QC, draw the box (90,230)-(890,1480) on an extracted frame, look at it, and fix anything outside before publishing.
10. Photo posts: build with `cd assets && python3 make_photo_reel.py OUT.mp4 "HOOK 1" "HOOK 2" AUDIO img1.jpg ...`. If TikTok cannot be fetched directly, the vidIQ tool vidiq_watch_shortform_content returns the slides of a /photo/ URL.
11. At the end of EVERY run, send the finished video file to the user with SendUserFile (display: render) so they can watch it, together with the per-platform status.
Touch only this repository. Never touch other repos.
